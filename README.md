# 🎬 Sistema de Gestión de Cine

Un sistema sencillo y eficiente desarrollado en **Java** para la administración de reservas en una sala de cine mediante consola.

## 🚀 Características
El programa ofrece una interfaz de menú intuitiva para:
- **Visualizar la sala**: Muestra gráficamente los asientos libres (O) y ocupados (X).
- **Reservar asientos**: Permite seleccionar fila y columna para marcar un asiento como ocupado.
- **Liberar asientos**: Cancela reservas existentes de forma rápida.
- **Consultar disponibilidad**: Estadísticas en tiempo real sobre asientos totales, libres y ocupados.

## 🛠️ Tecnologías
- **Lenguaje**: Java 17+
- **Entrada/Salida**: Scanner API (Consola)

1. Compila el archivo fuente:
   ```bash
   javac src/App.java -d bin
   ```
2. Ejecuta la aplicación:
   ```bash
   java -cp bin App
   ```
